### 🎯 Objective

### 🧩 Component Requirements

#### 1. Structure

* Create a reusable React component named: `Draggable3DCarousel`
* Main elements:

  * A centered container with **perspective (2000px)**
  * A `ring` element that holds all images in 3D space
  * Multiple `.img` panels (at least 10)
  * A full-screen invisible `dragger` layer for capturing interactions
  * A `vignette` overlay for cinematic edge fading

---

#### 2. 3D Layout

* Use `transform-style: preserve-3d` for all relevant elements
* Each image should:

  * Be rotated along the Y-axis (`rotateY`) evenly (360 / total images)
  * Be pushed outward using `translateZ` (~500px)
  * Have `transform-origin: 50% 50% 500px`
  * Have `backface-visibility: hidden`
* Arrange images in a perfect circular ring

---

#### 3. Visual Styling

* Theme: **Ferrari-inspired**

  * Background: pure black (`#000`)
  * Accents: deep red, subtle glow
* Images:

* Add a **vignette overlay**:

  * Gradient fading from black on left/right edges
* Ensure premium feel:

  * smooth edges
  * soft lighting illusion
  * no harsh transitions

---

#### 4. Entry Animation

* On component mount:

    * `y: 200`
    * `opacity: 0`
  * Use staggered animation
  * Duration: ~1.5s
  * Easing: `expo.out`

---

#### 5. Drag Interaction (Core Feature)

Use GSAP Draggable:

* Capture horizontal drag input
* On drag:

  * Calculate difference between current and previous X position
  * Rotate the `ring` using `rotationY`
* Ensure:

  * Smooth, fluid motion
  * Continuous rotation (no hard limits)
* Reset dragger position after drag ends

---

#### 6. Parallax Effect (Important)

* Each image must shift its **background-position dynamically**

* This creates a **depth/parallax illusion**

#### 8. Performance

* Use `will-change: transform`
* Avoid unnecessary re-renders
* Handle GSAP logic inside `useEffect`
